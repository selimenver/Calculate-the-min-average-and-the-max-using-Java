Number Analyzer in Java

This is a simple Java console program that reads three numbers from the user and calculates:

The smallest number

The largest number

The average of the three numbers

Features

Uses methods for each calculation (smallest, biggest, average)

Demonstrates basic user input handling with Scanner

Uses Math.min and Math.max for comparisons

Requirements

Java Development Kit (JDK) 8 or higher

A terminal or IDE (e.g., IntelliJ IDEA, Eclipse, VS Code)

How to Run

Clone or download the repository.

Open a terminal in the project directory.

Compile the program:

javac Main.java

Run the program:

java Main

Follow the prompts to enter three numbers. The program will output:

The smallest number

The biggest number

The average

Example
Enter 3 numbers
Your first number:
5
Your second number:
12
Your third number:
8
smallest: 5
Biggest: 12
Average: 8.333333333333334
Code Overview

smallest(int x, int y, int z) → Returns the smallest of three integers

biggest(int x, int y, int z) → Returns the largest of three integers

average(double x, double y, double z) → Returns the average of three numbers
